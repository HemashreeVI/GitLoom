Questions

Is it really free?

Yes. GitLoom runs entirely in your browser and the site it makes is a static file. GitHub Pages, Netlify and Vercel all host static files for free.

Does it need access to my GitHub account?

No. It only reads public data through GitHub's API. If you make lots of changes and hit GitHub's hourly limit of 60 requests, you can add a token with no permissions in the studio to raise it to 5,000. The token stays in your browser.

Will my site update when I push new code?

The downloaded file is a snapshot, which keeps it fast and private. Download again whenever you want to refresh it, or share the live link from the studio, which always fetches the latest data.

Can I edit the HTML afterwards?

Yes. It's one readable file with the styles at the top and a small script at the bottom. Change anything you like.

Can I use my own domain?

Yes. Add a CNAME file to your Pages repository and point your domain at GitHub. GitHub's Pages settings explain each step.
