          Publish on GitHub Pages

          1. Create a repository named username.github.io.
          2. Upload the downloaded index.html to it.
          3. Open Settings → Pages, set the source to the main branch and save.
          4. Your site goes live at https://username.github.io in about a minute.

          Netlify and Vercel work too: drag the file onto Netlify Drop.
